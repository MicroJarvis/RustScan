5. 损失函数计算

损失函数位于 src/training/engine/loss.rs，支持组合损失。

5.1 总损失公式

Ltotal = λl1⋅LL1 + λssim⋅LD-SSIM + λgrad⋅Lgradient

默认权重：λl1 = 0.8, λssim = 0.2, λgrad = 0.0。

5.2 L1 重建损失

标准 L1
loss=|pred-target|
Saturating L1
robust_delta > 0
loss=δ⋅|pred-target||pred-target|+δ
大残差（动态物体/遮挡）被饱和处理，梯度被平滑抑制。
Soft Outlier
outlier_threshold > 0
weight=w+(1-w)⋅τ|Δ|+τ
高残差像素保留可配置的梯度下限（outlier_weight ∈ [0,1]）。
动态遮挡掩码
训练后期启用
weight=clamp(τhigh-|Δ|τhigh-τlow,wmin,1.0)Lweighted=mean(L⊙weight)mean(weight)
默认在拓扑冻结 epoch 后激活，对动态/遮挡区域软抑制。

5.3 D-SSIM 损失

SSIM(x,y) = (2μxμy+C1)(2σxy+C2) (μx2+μy2+C1)(σx2+σy2+C2) Lssim=1-mean(SSIM_map)
参数值说明
窗口大小11高斯模糊核半径 = 5
σ1.5高斯核标准差
C₁(0.01)²亮度稳定常数
C₂(0.03)²对比度稳定常数

实现通过 Burn 的 conv2d 做可分离 2D 卷积（先水平后垂直），输入从 [H,W,C] 转为 NCHW 格式。

5.4 梯度损失

Lgrad = 12 ⋅ ( mean(|dx_pred-dx_target|) + mean(|dy_pred-dy_target|) )

在水平和垂直方向计算一阶差分的 L1 距离，增强边缘与细节保持。默认关闭（权重 0）。

7. Adam 优化器与学习率调度

7.1 Scaled Adam 优化器

src/training/engine/optimizer.rs 实现 AdamScaled，代码上维护 3 个参数张量的 Adam 状态（transforms、sh_coeffs、raw_opacities），但通过 scaling 张量把 transforms 内部拆成位置 / 旋转 / 尺度三组学习率。因此用户侧可以理解为 5 组独立学习率：

参数组初始 LR最终 LRScaling 张量形状
位置 (x, y, z)1.6 × 10⁻⁴1.6 × 10⁻⁶[1, 3] → 复制 3 次 (pos)
旋转 (quat: w,x,y,z)1.0 × 10⁻³可配[1,10] transforms scaling 的 4 列
尺度 (sx, sy, sz)5.0 × 10⁻³可配[1,10] transforms scaling 的 3 列
不透明度5.0 × 10⁻²可配[1] → broadcast 到 [N]
颜色 / SH 系数2.5 × 10⁻³可配[1, K, 1] → broadcast 到 [N,K,3]
Adam 更新公式（每组参数独立执行）
m1←β1m1+(1-β1)⋅grad m2←β2m2+(1-β2)⋅grad2 m^1←m11-β1t,m^2←m21-β2t θ←θ-(scaling⋅lr)⋅m^1m^2+ε

其中 β₁=0.9, β₂=0.999, ε=1e-8，无 weight decay（默认 0）。

7.2 指数学习率衰减

lr(t) = lrinit ⋅ exp ( ln ( lrfinallrinit ) ⋅ tT )

每个训练步调用 update_optimizer_lrs()，用 iteration-1 计算当前 LR，并重建 transforms / SH / opacity 的 scaling 张量。优化器的全局 lr 固定为 1.0，真正的学习率全部来自这些 scaling。

8. LiteGS 拓扑控制

拓扑控制是 3DGS 训练区别于传统 NeRF 的关键自适应机制。核心逻辑位于 src/training/topology/，由 should_apply_topology_step() 在每个 refine_every（默认 160）迭代 cadence 上触发。

8.1 拓扑调度参数

参数默认作用
densify_fromepoch 3开始 densify 的 epoch
densify_until80% 总 epochs停止 densify 的 epoch（自动计算）
densification_interval5 epochs两次拓扑更新之间的 epoch 间隔
refine_every160 iters拓扑校核步长（迭代数）
topology_freeze_after_epoch可配冻结所有拓扑更新（仅优化参数）
growth_freeze_after_epoch可配仅冻结增长，允许继续剪枝

注意：当前 schedule.rs 的实际触发主要看 refine_every、训练进度 95% 之前、freeze / prune_until / reset 配置；densify_from、densify_until 和 densification_interval 仍保留在 LiteGS 配置与 reference controller 中，但主 wgpu schedule 并没有按这些字段直接做 epoch 取模。

8.3 四种 Split Score 模式

Baseline
score = mean2d_grad — 原始 3DGS 的 post-projection 梯度大小。最简单直接的方式。
Abs
score = abs_grad_2d — AbsGS 风格，使用绝对值屏幕空间梯度。对小梯度但分布广的高斯更敏感。
AbsPixel
score = abs_pixel_grad_2d — per-pixel 绝对值梯度除以像素覆盖率，归一化到单像素级别。
AbsPixelDepth
score = abs_pixel_grad_2d × depth_scale — 同 AbsPixel，但乘以深度缩放因子 clamp((depth / γ·R)², 0, 1)，抑制近相机区域的过度 split。

8.4 Densify 选择与 Gaussian 分配

Step 1
计算替换容量：N_prune = prune_candidates 的数量。同时从非 prune 候选中按不透明度加权随机采样 N_prune 个替换源，用于“剪掉一些、补回一些”的稳定替换。
Step 2
额外增长：在 grow_candidates 中按 growth_weight 加权采样 extra_growth 个，数量来自 growth_select_fraction（默认 25%）和 growth_stop_iter。当前 budget 至少允许维持现有数量并加上本次请求，因此不会因为 max_initial_gaussians 小于当前数量而被迫缩回。
Step 3
Brush Refine：被选中的高斯变成一对：旧行原地改写为 BrushRefineExisting，同时追加 BrushRefineNew。两者沿旋转后的尺度方向向相反方向偏移，最大尺度轴减半，不透明度按 1 - sqrt(1 - opacity) 重新分配；随机标量来自 Box-Muller：√(−2·ln(u₁)) × cos(2π·u₂)。

8.5 三种 Prune 模式

模式剪枝条件
Thresholdopacity < 1/255 或 连续不可见 ≥ 10 epochs
Weight当 densify 启用时做 opacity 剪枝，否则仅不可见剪枝
VisibilityWeight上述条件 或 actual_visibility_ratio < 5% 且 opacity < 80%
