## P2 — Cleanup-failure bookkeeping regression cannot detect restoration

Locations: `rustscan-sfm/src/io/database.rs:1079-1084`, `:5972-5998`.

The test sets database_entry_deleted=true before the transaction and never
changes it inside the transaction. Its final true assertion passes whether
finish_failed_transaction restores deleted_before or correctly leaves the
current value alone. The rollback-failure hook also executes a real ROLLBACK
before returning a synthetic error, so it does not represent cleanup failure
with a still-active transaction. The original bookkeeping acceptance gap is
therefore not proved closed by this test.

Required action: make the initial and in-transaction flag values differ
(for example false before and true after an actual deletion), and simulate a
cleanup failure without first performing successful rollback. Assert both
error messages, transaction state, and unchanged current bookkeeping on
failed cleanup; explicitly clean up the test afterwards. The test must fail
if the error branch restores the pre-operation flag unconditionally. Keep
successful-cleanup tests for restoring both initial flag states. This is a
test-proof finding, not a demonstrated production bookkeeping corruption.

## P2 — Retry assertions still ignore reference identity and full payloads

Locations: `rustscan-sfm/src/io/database.rs:6322-6374` and
`rustscan-sfm/src/sfm/mapper.rs:19707-19738`.

The retry tests still check lengths, image-name sets and selected geometry
values via `.any(|(_, geometry)| ...)`, discarding pair IDs. Swapping the
payloads between image pairs would pass. Camera bindings and complete new
keypoint/descriptor contents are also not compared to expected results.
The merge failure/retry fixtures do not populate rigs, frames or pose priors,
so capturing those empty vectors does not exercise their rollback/reference
contracts. This falls short of the prior explicit request for complete retry
contents and correct references, despite the improved rollback snapshots.

Required action: use populated rig/frame/prior merge fixtures; compare retry
results against an independently specified expected logical state, with IDs
and references resolved by stable image/camera identity. At minimum assert
the exact pair ID AND full geometry/match payload together, image-to-camera
bindings, descriptor/keypoint payloads, and retained pre-existing rows. Cover
the nonempty relationship rows in late-failure rollback and successful retry.
Keep scope limited to these acceptance checks; no production redesign is
requested. Do not claim complete snapshot proof merely because a helper
captures fields that the test never asserts after retry.
