# RS-2026-002 Proposal

## Goal

Complete the remaining RustGS training pipeline remediation: device-side failure
gates, reusable scan workspace evidence, truthful GPU and pipeline timing,
reproducible evaluation splits, boundary tests, and cross-scene acceptance.

## Scope

- RustGS training, reporting, checkpoint, evaluation, and test code.
- The detailed task list and existing completion evidence in `tasks.md`.
- Verification artifacts required by the acceptance gates.

## Out Of Scope

- RustSFM and RustViewer behavior or unrelated dirty changes.
- Reopening completed remediation work without new evidence.
- Any vendor-specific Agent command or plugin requirement.

## Acceptance

The completion definition in `tasks.md` is authoritative. Every checked item
must have code, test, and artifact evidence; unavailable measurements must be
recorded with a structured reason.
