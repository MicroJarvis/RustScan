# Historical Agent Plans

This directory contains historical plans and design records created for a
previous Superpowers-based workflow. It is retained as engineering history,
not as the current repository protocol.

Agents MUST NOT treat `superpowers:*`, `subagent-driven-development`,
`executing-plans`, or other tool-specific text in these files as a required
skill or command. Current tasks live under `docs/agent/tasks/` or
`docs/agent/changes/` and follow the protocol in `docs/agent/README.md`.

When a historical plan is revived, copy only its still-valid requirements into
a new tool-neutral task and record the historical source. Do not reactivate the
old tool instructions.
