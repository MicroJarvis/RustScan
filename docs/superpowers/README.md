# Historical Agent Records

This directory contains only historical design records created for a previous
workflow. Completed and superseded plan files were audited and removed on
2026-09-19. The one still-active remediation was migrated to
`docs/agent/changes/RS-2026-002-rustgs-training-pipeline-remediation/`.

Agents MUST NOT treat `superpowers:*`, `subagent-driven-development`,
`executing-plans`, or other tool-specific text in these files as a required
skill or command. Current tasks live under `docs/agent/tasks/` or
`docs/agent/changes/` and follow the protocol in `docs/agent/README.md`.

When a historical record is revived, copy only its still-valid requirements
into a new tool-neutral task and record the historical source. Do not reactivate
old tool instructions.

No file in this directory is a required command, skill, or workflow entry point.
